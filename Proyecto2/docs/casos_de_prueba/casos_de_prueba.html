Cómo se ejecutaron

Cada caso es un archivo de examples/casos/. El script tests/prueba_casos.py lo analiza con el programa completo (analizador léxico, parser y generación de reportes) y compara cada resultado esperado, escrito a mano antes de ejecutar, con el resultado obtenido. Este documento lo genera ese mismo script, así que lo obtenido es siempre la salida real del programa.

Notación: TIPO línea:columna para errores; TIPO "lexema" línea:columna para tokens. Las posiciones empiezan en 1.
