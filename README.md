ejecucion y ejemplos de uso.

## Como ejecutar cada entrega

```bash
cd Practica1
python main.py
```

```bash
cd Proyecto1
python main.py entradas/horario_completo.hor
```

Ninguna de las dos requiere instalar librerias externas.
